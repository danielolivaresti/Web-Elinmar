# Web Elinmar

Sitio web corporativo y plataforma de servicios técnicos para **Ingeniería y Servicios Elinmar Ltda.**

## 📌 Descripción
Proyecto orientado a digitalizar la presencia y procesos de Elinmar, facilitando la visualización de servicios de soporte informático, mantenimiento y soluciones industriales.

## 🛠️ Tecnologías utilizadas
* HTML5 / CSS3 / JavaScript
* Git & GitHub
